## 3. Prototype power target

The prototype target of ≥10 dBm average per feed is **still plausible.**
- It needs about 12 dB back-off from the ADTR1107 OP1dB (23 dBm typ, 21 dBm min, 6–14 GHz table).
- Every stage before it runs with ≥20 dB margin.
- It depends on two unverified items:
  1. 100 MHz OFDM EVM/ACLR at 12 dB back-off without DPD;
  2. ADAR1000 gain and gain-control range at 8.4 GHz, since its data starts at 9.5 GHz.

Both are covered by condition C2.

## 4. Unresolved electrical/RF risks (full list: `H2A_UNRESOLVED_ISSUES.md`, 26 items)

| ID | Risk | Severity | Close by |
|---|---|---|---|
| R1 | **All regulators are placeholders** (U601–U608), and the negative-rail monitor U609 is a placeholder | blocks layout prep | power design (ADI suggests LT8609S + LT1931 for 4 ADAR1000) |
| R2 | **PA_BIAS OFF value conflict.** ADAR1000 p45 says −2.5 V; ADTR1107 VGG_PA abs max is −2 V. H2-A uses −1.75 V in firmware | high (device damage) | ADI question 5a |
| R3 | **VGG_PA 10 nF vs PA_BIAS switching.** 60 ns is specified into 1 nF; 10 nF gives about 0.65 µs or more per TDD edge | medium (TDD guard time) | ADI question 5c; eval-board value |
| R4 | **LNA powered during TX.** The design keeps VDD_LNA on and pinches the gate (Stingray style), unlike the ADTR1107 TX sequence | medium | ADI question 5b |
| R5 | **No bypass values** for ADAR1000 AVDD1/AVDD3 or ADTR1107 VDD_PA/VDD_LNA/VDD_SW/VSS_SW (not in datasheets) | blocks layout prep | eval-board schematics (ADI question 2) |
| R6 | **ADF4371 loop filter not designed;** RF8P single-ended level at 6.6 GHz not tabulated; RF8 is ON at power-up by default | blocks layout prep | ADIsimPLL; C4 bench; CE held low until programmed (drawn) |
| R7 | **AVA-183A+ bias tee not wired;** no gain/P1dB spec between 5 and 8 GHz | blocks layout prep | Fig 2 / PL-328; bench |
| R8 | **ADAR1000 SDO not tristated** on a shared bus (erratum) | low (firmware) | separate CSB per chip, as drawn; read back one chip at a time |
| R9 | **MCU pin/AF map provisional;** STM32 decoupling not placed | blocks layout prep | STM32CubeMX + ST DS |
| R10 | **TI glue-part values from memory** (TPS22810 CT/QOD, TPS3430 timing, INA226 straps, PCA9306 bias, TPS22810 EN threshold at 1.8 V) | blocks layout prep | TI datasheets |
| R11 | **N310 interface levels unverified** (IF port DC state, PPS level, GPIO/ATR mapping); N310 inter-channel phase is random per start/retune | medium | UHD docs; CAL-port loopback after every init/retune (drawn) |
| R12 | **Calibration network:** EP4RKU+ phase unbalance up to 19°, coupler directivity 19 dB typ | medium | one-time VNA characterisation; phase-matched layout |
| R13 | **No footprints** for custom ICs, Mini-Circuits parts or SMAs; ADF4371 EP size is ambiguous in the datasheet. The exposed pad is symbol pin `EP` on every custom part, so footprint pad numbers must match it (the LTC5553 datasheet calls it pin 13) | blocks layout | vendor land patterns |
| R14 | **Antenna / feed interface and thermal design** not done (H1 M5, M6) | separate WPs | EM + thermal studies |
| R15 | **Source copies:** ADI datasheets were read from mirrors (analog.com unreachable) | low | re-check revisions in a browser |

## 5. Gate decision

| Gate | Decision |
|---|---|
| Mixer | **LTC5553 selected** (`H2A_MIXER_DECISION.md`) |
| Preliminary schematic capture | **Done**, as a preliminary schematic |
| **PCB layout preparation** | **NO-GO** |
| PCB routing / Gerbers / fabrication | NO-GO (unchanged) |

Why it is NO-GO:
- ERC is not clean: 22 deliberate open pins.
- The power tree is still placeholders (R1).
- Mandatory bypass networks are missing (R5).
- The loop filter, LO-amplifier bias and TI glue values are not designed (R6, R7, R10).
- None of the H1.1 conditions C1 (ADAR1000 supply), C2 (8.4 GHz bench data) or C4 (LTC5553/ADF4371 at the operating
  point) has closed, and C3 still needs the project lead's acceptance.

Exit criteria to reach CONDITIONAL GO for layout preparation:
1. R1, R5, R6, R7, R9, R10 designed and drawn.
2. ERC at 0 violations (or each residual waived in writing).
3. R2 and R4 answered by ADI or decided by the project lead.
4. Vendor footprints for all parts (R13).
5. C1 closed. C2 and C4 have at least eval-board data, or an explicit risk acceptance.

Work that may proceed in parallel, because it does not depend on schematic freeze:
- building the footprint library from vendor land patterns;
- choosing the stackup and material (ADF4371 DS recommends Rogers 4350/4003/3003);
- antenna EM design;
- the eval-board bench plan for C2/C4, cabled and attenuated with no OTA, using the draft inquiry once it is approved.
