# H2-C peripheral fixes and decoupling: implementation report (IMPL_PERIPH)

All edits were made through the KiCad MCP tools. Nothing was committed.

## What was done
- **Expected netlist first.** `expected_periph.json` (69 entries: 66 new parts + changed pins on U610/U651/U701) was generated by `tools/gen_expected_periph.py` before placement. Local power-sheet nets are written `PWR_I2C3_SDA` / `PWR_PCA_VREF2` (JSON only; real nets unchanged).
- **Check after:** exported netlist (`periph/net_after/`) matches the JSON: 0 mismatches (value, footprint, every pin net).
- **A5 bf1..bf4** (per ADAR1000, row at y=259.08): C{c}05 1µF 6.3V X7R, C{c}06 10nF 10V X7R, C{c}07 100pF 50V C0G on +3V3_RF; C{c}08 10nF 10V X7R, C{c}09 100pF 50V C0G on -5V_BF. C{c}05 MPN GRM155R70J105KA12D (Stingray part, already 0402).
- **A5 fe1..fe4** (per tile, row at y=250.19): C{c}40 10nF + C{c}41 100pF on -3V3_SW; C{c}42 1µF 10V X7R + C{c}43 10nF + C{c}44 100pF on +5V_PA_C{c}. Per ADTR1107 VDD_PA: C{c}50..C{c}53 4.7µF 10V X5R on +5V_PA_C{c} at y=60.96 above UFE{4(c-1)+1..4}.
  - Existing CREG 1µF (C{c}01..04) and VGG_PA 10nF (C{c}11..14) untouched.
  - Note text on every bf/fe sheet: "decoupling per ADI Stingray 02_059522 Rev B (per-tile set); per-pin values not documented".
- **A4 MCU (mcu.kicad_sch):** C703/C704/C705 100nF + C706 4.7µF (VDD 23/35/48), C707 10nF + C708 1µF (VDDA), C709 100nF + C710 1µF (VREF+), all +1V8_DIG/GND, 0402. VBAT: no cap. Sheet note records the ST rule (VREF+ = VDDA below 2 V) and VBAT UNRESOLVED.
- **A4 INA226:** U610 A0 (pin 2): GND global label at (72.39, 274.32) and its stub removed; pin wired to local I2C3_SDA. U610 = A1 GND / A0 SDA = 0x42. U611 stays 0x40.
- **A4 PCA9306:** C629 100pF 50V C0G 0402, PCA_VREF2 (local) to GND (global label), at (411.48, 279.4).
- **MCU text:** TPS3430 note "SLVSxxx" -> "SBVS366A" (remove_text + add_text). See deviation 5 for the position.
- **U651 PGOOD:** pin 9 -> new global net PG_5VPA; R676 100k 1% 0402 pull-up to +1V8_DIG on pwr_main at (487.68, 177.8); U701 pin 16 (PC4) NC flag removed and wired to PG_5VPA. Note text added on pwr_main.
- Every cross-sheet net added is a passive global label at the stub end; I2C3_SDA and PCA_VREF2 stay local on power.kicad_sch. No NC flags, no PWR_FLAGs, no ERC severity changes.

## Ref numbering
- A5 suggested refs used as-is (C{100c+5..9}, C{100c+40..44}, C{100c+50..53}); none collided. Only 5 of the 9 reserved C{100c+40..48} refs are needed.
- MCU C703–C710 (A4 says C703+; C701/C702 exist; C761+ belong to IMPL_POWER).
- **Choices not given by AMENDMENTS:** C629 (power sheet uses C621–C628) and R676 (pwr_main uses up to R675; R665/R671 skipped because IMPL_POWER lists them as unplaced spec refs). Both checked unused in the before-netlist.

## Deviations
1. **+5V parts rated 10 V** (C{c}42 1µF X7R, C{c}50..53 4.7µF X5R) instead of Stingray's 6.3 V (A5 / PERIPH_SPEC judgement: 5.18 V worst case on 6.3 V is too tight). No MPN set: a 4.7µF/10V X5R 0402 part was not checked against a datasheet or stock.
2. **0402 instead of Stingray 0201** for the 10nF/100pF/4.7µF parts (A5 footprint rule). MPN left empty on those (Stingray MPNs are 0201 parts: GRM033R71A103KA01D, GRM0335C1H101JA01D, GRM035R60J475ME15D).
3. **MCU caps** have values only ("100nF", "4.7µF", ...); DS12589 gives no dielectric/rating, so no MPN.
4. **Schematic placement only:** the decoupling caps are in rows away from the ICs (≥12 mm spacing rule); placement close to pins is a PCB task.
5. **TPS3430 note position:** the original text was left-justified at about (116.84, 40.64); add_text has no justify option and writes centred text, so the replacement is centred at (297.18, 40.0) to cover the same span (verified on an SVG export: same baseline; left edge 116.30 vs 117.05 mm before, because "SBVS366A" is one character longer). Content is identical except SLVSxxx -> SBVS366A.
